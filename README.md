# TCG — The Consulting Group

Official website for **The Consulting Group (TCG)**, a full-spectrum consulting firm based in Bengaluru, India.

## Stack

- Pure HTML/CSS/JS — no framework, no build step
- Embedded assets (logos, fonts via Google Fonts)
- Deployed on Vercel

## Structure

```
tcg-website/
├── index.html       # Full website — single file
├── vercel.json      # Vercel config
├── .gitignore
└── README.md
```

## Deployment

Hosted on Vercel. Every push to `main` auto-deploys.
